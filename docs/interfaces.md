# 固件软件接口

| 接口 | 串口参数 | 软件契约 |
| --- | --- | --- |
| 双车调度（Zigbee） | 9600 bit/s，8N1 | 1 车发出 Q1～Q4 阶段命令；2 车按本地状态处理。1 车主循环未处理反向停车通知。 |
| 视觉输入（K230） | 38400 bit/s，8N1 | MCU 为 Q6 预留超车、停车状态帧；本仓库没有配套视觉端程序。 |
| 调试与参数串口 | 115200 bit/s，8N1 | 独立于调度和视觉链路。 |

灰度和 IMU 提供循迹、姿态输入，2 车另读取 DL1B 距离传感器。帧格式与命令值见[通信协议](protocol.md)，各赛题流程的实现状态见[已知问题](known-issues.md)。
